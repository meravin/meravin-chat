# hello-mac

> **仓库里还有 [YourChat](YOURCHAT.md)** —— 一个 iOS 聊天 App：两个独立 AI
> 加三人群聊、基于 HealthKit 的首页仪表盘、双人日记，跑在一个 Node.js
> 消息桥上。找的是这个的话直接看那边。

这是我在新 MacBook Pro 上的第一个 GitHub 项目。

## 运行

```bash
python3 hello.py
```

当系统语言环境变量（`LC_ALL` / `LC_MESSAGES` / `LANG`）以 `zh` 开头时，脚本会自动输出简体中文问候语，否则输出英文。
